- [ ] 1.1 Let `CliBackend::new` take the `GitVersion` of the start-up check and keep `Capabilities { merge_tree, ahead_behind, is_base }` (Git 2.38, 2.41, 2.47), which the fake backend lets tests set (design, decision 14); verify unit tests of the capabilities at 2.34, 2.38, 2.41 and 2.47, and that the app passes the version of its check
- [ ] 1.2 Add `Backend::facts(repo, cancel)` returning `RepositoryFacts`: `git config --list -z` parsed once into the overrides that neutralise filters, whether any `merge.<name>.driver` is configured, the remotes with `url.<base>.insteadOf` applied and each branch's upstream; the common Git folder from `git rev-parse --path-format=absolute --git-common-dir`; and every local and remote-tracking branch with its commit and upstream and the target of `refs/remotes/origin/HEAD` from one `for-each-ref`; let `Backend::summary` take the overrides from the facts instead of reading the configuration itself (design, decision 2); verify tests in `crates/gitbull-git/tests/` against real repositories with two remotes, an `insteadOf` rule, an upstream, a merge driver and a linked worktree, and that a summary runs no `git config`
- [ ] 1.3 Add the detection of a branch's base with `for-each-ref --format=%(refname)%00%(is-base:<branch>)` over local and remote-tracking branches without the branch and its own remote-tracking branches, where the capabilities allow it (design, decision 3); verify tests against a real repository with `main` and `dev` and branches started from each, run on the Git at hand and asserting the fallback when it is older than 2.47
- [ ] 1.4 Add the counts against a base: `%(ahead-behind:<base>)` once per distinct base where the capabilities allow it, else `git rev-list --left-right --count`; a detached HEAD through `rev-list`; and the lines of a branch through `git merge-base` and `git diff-tree -r --numstat -z -M` (design, decision 4); verify tests against real repositories for 3 ahead and 1 behind, a detached HEAD, and +120 −40 in 5 files, with both code paths forced through the capabilities
- [ ] 1.5 Add `Git::run_quarantined`: a new folder in the system's temporary folder as `GIT_OBJECT_DIRECTORY`, the repository's object folder as `GIT_ALTERNATE_OBJECT_DIRECTORIES`, the folder removed after the process ends, also when it is cancelled; move `tempfile` to the dependencies of `gitbull-git` (design, decision 6); verify tests that a `merge-tree --write-tree` in quarantine leaves the object folder of a real repository unchanged, reads objects of an alternate the repository itself names, and leaves no temporary folder after success, failure and cancel
- [ ] 1.6 Add whether a branch is merged into a base and whether merging would conflict: ancestor, then `git cherry` for at most 500 commits ahead, then, where the capabilities allow it and no merge driver is configured, `git merge-tree --write-tree` in quarantine with the filters neutralised, its tree compared with the base's tree and its exit status read as a conflict (design, decision 5); verify tests against real repositories for a merge commit, a rebase merge, a squash merge, a conflicting branch, a branch that is neither, a repository with a merge driver (no prediction, said so) and Git older than 2.38 forced through the capabilities
- [ ] 1.7 Add the commits after a seen commit (`rev-list --count`, `merge-base --is-ancestor`, `log -n 51 --format=%H%x00%s%x00%ct`), the uncommitted files with their lines (`git diff --numstat -z HEAD` with the filters neutralised, `--no-ext-diff --no-textconv`), and the summary's newest modification of a changed path apart from `last_active` (design, decisions 7 and 9); verify tests for two commits after a seen one, a rewritten branch, 70 commits listed as 51, and uncommitted files with lines including a new file
- [ ] 1.8 Add the diff for the AI context: `git diff-tree -p -M <merge-base> <branch>` and `git diff -p HEAD` with `--no-ext-diff --no-textconv` and the filters neutralised, read as a stream that keeps 2,000 lines and counts the rest, with blobs above 1 MiB found through `--raw` and `cat-file --batch-check` and excluded by pathspec (design, decision 12); verify tests for a diff of 300 and 40 lines kept whole, one of 3,500 lines cut with 1,500 counted, a binary file and a 2 MiB file named only
- [ ] 1.9 Extend `tests/hardening.rs` with every new command: a monitor hook in a repository and in a worktree, an external diff tool and a text conversion filter, a merge driver assigned by the attributes, and a clean filter with `merge.renormalize`, none executed; the index, the references and the objects unchanged after a full comparison (design, decisions 5 and 6); verify the scenarios "Comparison with the base" of "Read-only operation" and "Merge driver is configured" and "Diff copied as AI context" of "Untrusted repositories" in `git-integration`
