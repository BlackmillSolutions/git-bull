- [x] 1.1 Add `Backend::worktrees(repo, cancel)` in a new module `gitbull_git::worktrees`: `git worktree list --porcelain` through the hardened invocation and `run_cancellable`, parsed into path, HEAD, branch and whether a worktree is bare, detached or prunable, with the main worktree first, and a folder that is gone or not a repository told apart from a refusal of Git; implement it in `CliBackend` and in the fake backend (`with_worktrees`) (design, decision 5); verify unit tests of the parser with the output of Git 2.34 and of a newer Git with `locked` and `prunable`, a bare main repository and a detached worktree, and tests in `crates/gitbull-git/tests/` against a real repository with two worktrees, a deleted folder and a cancelled call
