# git-bull 0.1.0

The first release, from the first two milestones: a read-only viewer for
Git repositories, with the history and its graph, commit details and diffs,
the working-copy status, commit search, file history and blame, and the
improvements of its interface. It never changes a repository, and it stays
fluid on histories of more than a million commits; see
`docs/benchmarks.md`.

## Improvements of the interface

The second milestone:

- A design system: a teal accent, rounded corners and a visible focus ring,
  the fonts Inter and JetBrains Mono, and the settings "Colour vision"
  (Standard, Red-green and Blue-yellow, with the light and the dark theme)
  and "Interface size" (100 % to 150 %, also with Ctrl+Plus, Ctrl+Minus and
  Ctrl+0).
- The long lists scroll smoothly with the mouse wheel and the touchpad.
- On Windows and Linux, an own title bar holds the tabs; on macOS, the tabs
  sit beside the system's buttons. Tabs can be reordered by dragging them
  or with Ctrl+Shift+Page Up and Page Down. The setting "Use the system
  title bar" brings back the system's.
- Dividers and column edges can be dragged, also between the details of a
  commit and its changed files, and in the file history, which gets
  headers.
- In the diff, the words that changed within a line stand out, invisible
  characters and line endings can be shown, F7 and Shift+F7 jump between
  hunks, and the lines hidden between them can be revealed.
- In the commit details, buttons copy the hash and the message, web
  addresses open in the browser, and every file shows the lines it added
  and removed. The file lists there and in File status can be shown as
  trees and filtered by name (Ctrl+L).
- The sidebar marks the view that is shown, however it was opened.
- A home tab replaces the chooser: the pinned and the recent repositories
  with their worktrees, each with its branch, its changed files and any
  conflict, a filter, and a context menu.

## Packages

Windows x64, macOS on Apple silicon and on Intel, and Linux x64 as AppImage
and `tar.gz`. How to install them, and what each system needs, is in the
README. The packages carry no developer signature.
