# git-bull 0.1.0

The first milestone: a read-only viewer for Git repositories, with the
history and its graph, commit details and diffs, the working-copy status,
commit search, file history and blame. It never changes a repository, and
it stays fluid on histories of more than a million commits; see
`docs/benchmarks.md`.

## Packages

Windows x64, macOS on Apple silicon and on Intel, and Linux x64 as AppImage
and `tar.gz`. How to install them, and what each system needs, is in the
README. The packages carry no developer signature.
